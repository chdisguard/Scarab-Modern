# Авторы и лицензии

- **Scarab** — [fifty-six и участники проекта](https://github.com/fifty-six/Scarab). Этот репозиторий является неофициальным форком. Лицензия менеджера: [GPL-3.0](LICENSE).
- **Hollow Knight Modding API** — [hk-modding и участники проекта](https://github.com/hk-modding/api). Порт для Unity 6 / Hollow Knight 1.5.12620: [PR #164](https://github.com/hk-modding/api/pull/164). Дополнительные исправления: [SFGrenade/api PR #5](https://github.com/SFGrenade/api/pull/5).
- Точные версии исходников API и происхождение локальных изменений: [vendor/api-provenance.json](https://github.com/chdisguard/Scarab-Modern/blob/modern-unity6/vendor/api-provenance.json). Лицензии API и MonoMod сохранены в [vendor/api/LICENSE](https://github.com/chdisguard/Scarab-Modern/blob/modern-unity6/vendor/api/LICENSE) и соответствующих папках `vendor/api`.
- **DebugMod** — [TheMulhima и участники проекта](https://github.com/TheMulhima/HollowKnight.DebugMod), использован для проверки совместимости; мод скачивается из каталога отдельно.
- **.NET SDK** — [Microsoft и участники .NET](https://github.com/dotnet/sdk). В Windows-релиз включена официальная portable-сборка SDK; её лицензия и ThirdPartyNotices находятся в `tools/dotnet`.

Hollow Knight принадлежит Team Cherry. Файлы установленной игры и сохранения не входят в менеджер. Сторонние библиотеки сохраняют лицензии своих авторов.
