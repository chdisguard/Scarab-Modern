# Scarab Modern

Рабочий форк [Scarab](https://github.com/fifty-six/Scarab) для **Hollow Knight 1.5.12620 (Unity 6)** с Modding API v78. Установка и работа DebugMod проверены в игре.

## Скачать и запустить

1. Скачайте **Scarab-Modern-2.8.5-win-x64.zip** из [последнего релиза](https://github.com/chdisguard/Scarab-Modern/releases/latest).
2. Распакуйте архив целиком и запустите **Scarab.exe**.
3. Выберите папку Hollow Knight и установите нужные моды.

Windows x64. Всё необходимое для запуска менеджера и подготовки API включено в архив; отдельно устанавливать .NET или SDK не нужно. Для загрузки модов и компонентов API нужен интернет.

Авторы, использованный Modding API и лицензии: [CREDITS.md](CREDITS.md).
